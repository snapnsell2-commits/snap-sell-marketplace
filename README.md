# Snap & Sell Marketplace

Build a modern marketplace called Snap & Sell. Include responsive design (desktop, tablet, mobile), dark and light mode, authentication (email and Google), user profiles with profile picture, username, bio, and location, product listings with multi-image upload, title, description, price, category, condition, and quantity, seller profiles, product detail pages, search and category filters, wishlist, and recently viewed products. Set up a scalable database structure using Lovable Cloud.

This project was built with [Lovable](https://lovable.dev).
